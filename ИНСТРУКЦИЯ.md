# Как выложить сайт и пользоваться админкой

Эта инструкция для того, кто не программирует. Ничего устанавливать не обязательно: всё делается в браузере.

## Что как устроено (в двух словах)

- **Сайт** — это обычные файлы из этой папки `site`: страница `index.html`, стили, скрипт, фото в `assets`, а все тексты — в папке `content` (файлы `.json`). Сервер с базой данных не нужен.
- **GitHub** — бесплатное хранилище этих файлов («репозиторий»). Он же бесплатно показывает сайт в интернете (это называется **GitHub Pages**). Адрес будет вида `https://ВАШ-ЛОГИН.github.io/cpa-site/`.
- **Админка** — по адресу `…/cpa-site/admin/`. Это готовая программа **Sveltia CMS**: в ней формы на русском, где можно поправить хронику, выставки, публикации, подписи к фото, контакты — на 5 языках — и загрузить фото или PDF. Когда вы нажимаете «Сохранить», админка сама записывает изменения в GitHub, а через 1–2 минуты сайт обновляется.

## Шаг 1. Завести аккаунт GitHub

1. Откройте https://github.com/signup и зарегистрируйтесь (почта, пароль, логин). Логин будет частью адреса сайта, например `cpa-rggu`.
2. Подтвердите почту.

## Шаг 2. Создать репозиторий

1. Вверху справа нажмите **«+» → New repository**.
2. **Repository name:** `cpa-site` (можно другое — тогда и в шаге 4 впишите его).
3. Выберите **Public** (бесплатный GitHub Pages работает только для публичных репозиториев).
4. Галочки «Add a README» и прочие **не ставьте**. Нажмите **Create repository**.

## Шаг 3. Вписать имя репозитория в настройки админки — ✅ сделано

Репозиторий проекта принадлежит организации Центра: **https://github.com/cpa-rggu/cpa-site**. Он вписан в `admin/config.yml` (строка `repo: cpa-rggu/cpa-site`).
Сайт: **https://cpa-rggu.github.io/cpa-site/**, админка: **https://cpa-rggu.github.io/cpa-site/admin/**.
(Старый адрес projectclaudeuhuru.github.io больше не работает — репозиторий перенесён в организацию.)

## Шаг 4. Загрузить файлы сайта

1. На странице нового репозитория нажмите ссылку **«uploading an existing file»** (или **Add file → Upload files**).
2. Откройте в Проводнике папку `site`, выделите **всё её содержимое** (Ctrl+A) — именно содержимое, а не саму папку `site` — и перетащите в окно браузера. Скрытый файл `.nojekyll` тоже должен попасть (если Проводник его не показывает — включите «Вид → Показать → Скрытые элементы»).
3. Дождитесь, пока загрузятся все файлы (их около 75), внизу нажмите **Commit changes**.
4. Проверьте: в репозитории сразу видны `index.html`, папки `admin`, `assets`, `content`, `css`, `js`.

> Если браузер не даёт перетащить так много файлов — загрузите в два приёма: сначала папку `assets`, потом остальное.
> Удобная альтернатива — программа **GitHub Desktop** (https://desktop.github.com): «Clone repository» → выбрать папку → скопировать туда файлы → «Commit» → «Push».

## Шаг 5. Включить GitHub Pages

1. В репозитории откройте **Settings → Pages** (меню слева).
2. **Source:** *Deploy from a branch*. **Branch:** `main`, папка `/ (root)`. Нажмите **Save**.
3. Через 1–2 минуты вверху этой страницы появится адрес сайта: `https://ВАШ-ЛОГИН.github.io/cpa-site/`. Его и можно показывать.

## Шаг 6. Вход в админку

Сейчас вход сделан самым простым способом, без дополнительных серверов: **по токену доступа** (это как отдельный пароль только для этого сайта).

1. Создайте токен: GitHub → ваш аватар справа вверху → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - **Token name:** `админка сайта ЦПА`.
   - **Expiration:** например, 1 год (потом создадите новый).
   - **Resource owner:** организация `cpa-rggu` (не личный аккаунт!).
   - **Repository access:** *Only select repositories* → выберите `cpa-site`.
   - Если GitHub напишет, что токен ждёт одобрения: организация `cpa-rggu` → **Settings → Personal access tokens → Pending requests** → одобрить.
   - **Permissions → Repository permissions → Contents:** *Read and write*. Больше ничего не нужно.
   - Нажмите **Generate token** и скопируйте строку, которая начинается с `github_pat_…`. Она показывается **один раз**.
2. Откройте `https://ВАШ-ЛОГИН.github.io/cpa-site/admin/`, нажмите **«Войти с помощью токена доступа»** и вставьте токен.
3. Браузер запомнит вход. На чужом компьютере после работы нажмите на аватар в админке → «Выйти».

**Важно:** токен — как пароль. Никому его не пересылайте и не вставляйте в файлы сайта. Если он утёк — удалите его на той же странице GitHub и создайте новый.

**Кнопка «Войти через GitHub»** в админке пока работать не будет: для неё нужен маленький бесплатный сервер-посредник (Sveltia CMS Authenticator на Cloudflare Workers). Если позже в админку захотят входить другие сотрудники — это можно настроить, Claude поможет. Для одного редактора токена достаточно.

## Как редактировать

1. Откройте админку → слева разделы: **Хроника, Выставки, Публикации, Авторы, Сюжеты, Экспонаты (QR), Обложка (фото на орбитах), Тексты сайта, Источники фото**.
2. В каждом поле с текстом — пять строк: Русский, English, Français, Português, Kiswahili. Обязателен только русский; если перевода нет, сайт покажет английский.
3. Фото и PDF: кнопка у поля «Фото»/«PDF статьи» → «Загрузить». Файлы попадают в папку `assets`.
4. Нажмите **«Сохранить»**. Через 1–2 минуты обновите сайт (если не видно изменений — Ctrl+F5).

Квадратные скобки `[...]` в текстах — заглушки (контакты, текст «О Центре», даты выставок). Выставки помечены «ПРИМЕР» — галочка «Пометка ПРИМЕР» в разделе «Выставки» снимается, когда данные станут настоящими.

## Страницы сайта и их адреса

| Страница | Адрес | Где править |
|---|---|---|
| Главная | `…/cpa-site/` | Хроника, Выставки, Публикации, Обложка, Тексты сайта |
| Сюжет | `…/story.html?id=africa` (коды: aswan, africa, tanganyika, sa) | Сюжеты |
| Экспонат по QR | `…/exhibit.html?n=03.14` | Экспонаты (QR) |
| Выставка | `…/exhibition.html?id=dar` | Выставки (поля «Страница: …») |
| Публикации | `…/publications.html` | Публикации, Авторы |

- **Новый сюжет:** «Сюжеты» → «Добавить сюжет», придумайте код латиницей (например `algeria`). Чтобы на него вела хроника — в «Хронике» у нужного года впишите `story.html?id=algeria`.
- **Новый экспонат:** «Экспонаты (QR)» → «Добавить экспонат», номер как на стенде. QR-код на стенде делайте на адрес `https://cpa-rggu.github.io/cpa-site/exhibit.html?n=НОМЕР` (любой бесплатный генератор QR-кодов).
- **Форма «Добавить публикацию»** ничего не хранит и никуда не отправляет сама: она открывает у учёного почту с готовым письмом. Куда придёт письмо — «Тексты сайта» → «Страница публикаций и форма» → **ПОЧТА ДЛЯ ЗАЯВОК** (если пусто — почта Центра из «О Центре и контакты»). Получив письмо, вы сами добавляете статью в «Публикации».

## Посмотреть сайт у себя на компьютере (необязательно)

Если просто дважды щёлкнуть `index.html`, браузер не даст странице прочитать тексты из папки `content`. Нужно запустить маленький сервер:

1. Откройте папку сайта `D:\Проект сайта\github\cpa-site` в Проводнике, в адресной строке напишите `powershell` и нажмите Enter.
2. Выполните:

```bash
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

3. Откройте в браузере `http://localhost:8080/`. Остановить сервер — Ctrl+C в окне PowerShell.

## Свой адрес (на будущее, РГГУ)

- **Поддомен РГГУ на GitHub Pages** (например, `cpa.rggu.ru`): IT-служба РГГУ добавляет DNS-запись `CNAME cpa → ВАШ-ЛОГИН.github.io`, а вы в **Settings → Pages → Custom domain** вписываете `cpa.rggu.ru` (GitHub сам создаст файл `CNAME`). Сайт и админка продолжат работать как сейчас.
- **Хостинг РГГУ** (сайт лежит на их сервере): см. заготовку `tools/deploy-ftp.yml.example` — после каждого сохранения в админке сайт будет сам копироваться туда по FTP. Все ссылки на сайте относительные, поэтому переезд не требует правок кода.

## Что Claude может делать сам

Все тексты лежат в понятных файлах `content/*.json` (по полю на каждый язык). Claude может напрямую править их и делать переводы на все пять языков, а вы потом загружаете обновлённые файлы в GitHub (или они попадают туда через GitHub Desktop).
