## Отличия от макета (осознанные)

- Ссылки на ещё не сделанные страницы (сюжеты, экспонат по номеру, страница выставки, все публикации, «добавить статью») показывают сообщение «Этот раздел появится на следующем этапе» вместо перехода на несуществующую страницу. В макете у 1960, 1961 и 1994 годов — «Открыть сюжет»; сейчас везде «Сюжет готовится», пока поле «Ссылка на сюжет» пустое.
- На баннере «Сейчас» добавлена метка «ПРИМЕР» (в макете её не было, но по ТЗ все примеры должны быть помечены).
- Подписи к фото хроники на телефоне — полные (в мобильном макете были сокращённые).
- Названия статей и журналов есть только на русском и в авторском английском варианте; на FR/PT/SW показывается английский (как в макете). Новые переводы названий не делались, чтобы не менять их смысл.
- Добавлены новые тексты (переведены на 5 языков): «Этот раздел появится на следующем этапе…», заголовок «Источники фотографий», «[автор и лицензия уточняются]».

## Где что лежит

| Путь | Что это |
|---|---|
| `index.html`, `css/style.css`, `js/main.js` | главная страница |
| `content/ui.json` | надписи, кнопки, заголовки, контакты (5 языков) |
| `content/chronicle.json` | хроника: годы, тексты, фото и подписи |
| `content/orbits.json` | фото и подписи на орбитах обложки + неподвижная раскладка |
| `content/exhibitions.json` | выставки (ПРИМЕР) |
| `content/publications.json` | публикации (с аннотациями, DOI — для будущей страницы) |
| `content/credits.json` | авторы и лицензии фото |
| `assets/` | фото, логотипы, PDF (имена файлов как в `cpa-site/assets/_index.tsv`) |
| `admin/index.html`, `admin/config.yml` | админка (config создаётся скриптом `tools/make-cms-config.ps1`) |
| `tools/serve.ps1` | локальный сервер для просмотра без Node/Python |
| `tools/deploy-ftp.yml.example` | заготовка автовыкладки на хостинг РГГУ |
